## 2. 透视标定（单应性）方法

### 2.1 标准流程（OpenCV）

- 恰好 4 对点：`cv2.getPerspectiveTransform(pts1, pts2)`——4 点中任意 3 点不共线；对单点噪声敏感
- **工程推荐（>4 点）**：`cv2.findHomography(src, dst, cv2.RANSAC, ransacReprojThreshold=3.0)` → 用内点再最小二乘精化（`method=0`）
- 建议流程：采 **8~12 对以上**地面控制点（近/中/远 + 左右铺开）→ RANSAC（阈值 3px）剔外点 → 全内点精化 → 报告控制点 RMSE（像素），验收时换算为米（GSD）
- 来源：OpenCV 官方文档（geometric transformations）；findHomography 方法学（RANSAC/LMEDS/0 区别）

### 2.2 高位交通相机的实操要点

- **可用参照物**（中国标线尺寸，作世界坐标真值）：
  - 车道分界线宽 15cm；同向虚线（≥60km/h）线长 6m、间隔 9m
  - 人行横道条纹宽 40/45cm、间隔 60cm；停止线宽 40cm
  - 车道宽度：CJJ 37-2012——混行车道 >60km/h 取 3.75m、≤60km/h 取 3.5m
- **标定点必须是地面平面上的点**（标线中心/端点、路缘石），不能用车辆自身；计数锚点用检测框**底边中心**（`Position.BOTTOM_CENTER`）
- 来源：GB 5768.3/GB 51038/CJJ 37-2012（尺寸为检索汇总，用前核规范原文）；supervision speed_estimation 官方示例

### 2.3 重投影误差 ≤3px 的含义与误差来源

- 3px 与 findHomography 默认 RANSAC 阈值同量级，常规分辨率下属"良好"；**该指标只对控制点附近有效，远处外推会放大**
- 若 1px ≈ 2~5cm（GSD），3px ≈ 6~15cm；更严谨的验收应报告"地面世界坐标反投影误差（米）"
- 主要误差来源：
  1. **镜头畸变**——单应模型假设针孔+平面；广角/鱼眼**必须先内参去畸变再标定**（宽角镜头不去畸变无法稳定检测消失点，arXiv:2001.07243）
  2. **相机俯角**——近水平视角对俯仰误差最敏感；俯角越大越稳定（Kanhere & Birchfield, IEEE T-ITS; DOI 10.1109/TITS.2010.2045500）
  3. 控制点选取误差（标线磨损/阴影/积水）与共线点集病态解
- **建议验收口径**：「标定控制点 RMSE ≤3px **且** 离控制点最远检查点 ≤5~8px，记录去畸变前后对比」

### 2.4 开源参考实现

- **roboflow/supervision `ViewTransformer`**（首选）：`SOURCE`（画面 4 点）↔ `TARGET`（米制矩形）经 `getPerspectiveTransform` 逆透视，逐机位重标；配合 ByteTrack + 1s 滑窗算速度
- Tensionteng/YOLOV8-Vehicle-Speed-Estimation：用「6m 虚线+9m 间隔」自动推世界尺度（思路参考）
- Ultralytics speed-estimation 官方指南（同款透视方案）

## 3. 冻结标注集规范

### 3.1 类别设计

- 一期冻结类别建议：`car / van / bus / truck / other`，对照 GA 802-2019（公安部机动车类型）与厅规划字〔2010〕205 号两级分类（折算系数 1/1.5/3/4）
- **taxi 单列判据**：仅在「顶灯 + 本地固定涂装」稳定可辨时单列；否则并入 car + `livery/roof_sign` 属性（出租车识别专利 CN103093249B 的判据：尺寸+顶灯+涂装）
- 顶灯按「车体一部分」标注（不单独出框）

### 3.2 小目标/密集场景注意事项

- 最小尺寸：框短边 **≥15×15px** 才标；<10px 不标（Roboflow UAV 指南）；小目标须收紧容差
- 遮挡分级：可见度 ≥95% 不标记 / 20~95% 标整框+`occluded` / ≤20% 不标
- 截断：可辨识即标，框到边缘+`truncated`
- 密集重叠：不可分辨的 >5 个重叠目标可整块单框；忽略区用 ignore 框
- 评测同时报告 **IoU=0.5 与 0.75 两档**，小目标单独统计

### 3.3 工具选型

| 工具 | License | 关键能力 | 定位 |
|---|---|---|---|
| **CVAT** | MIT | **原生视频 Track 模式**（键帧+插值）、自动 Tracker、任务分配/审查流 | **主选**（标注-抽检-冻结闭环） |
| X-AnyLabeling | GPL-3.0 | YOLO/SAM 预标注 + 视频多目标跟踪 | 备选（单人+有 GPU） |
| labelImg / labelme | MIT | 纯框 / 框+多边形，单机 | 轻量兜底 |

- 抽帧策略：同机位以 **1 帧/1~2 秒**为起点（连续帧近重复）；6 段视频抽几百帧即可覆盖
- 质量抽检：双人独立标注 + 差异第三人仲裁；金标插入混检；一致性参考线 Cohen's Kappa ≥0.8、mean IoU ≥0.88（MicroVision 数据集实测值）；抽检比例 10~20%（经验值）；**冻结=导出包（COCO/YOLO+图片清单+文件哈希），只增版本不改历史**

## 4. 人工计数对账规程（校验视频统计口径）

### 4.1 权威依据

- **FHWA《Traffic Monitoring Guide》2022**：计数须做一致性检查；**分类数据精度 ≤10%**；质量控制规则成文；不随意剔除"不像常规"的数据（fhwa.dot.gov/policyinformation/tmguide/2022_TMG.pdf）
- **ITE 口径**：人工计数以 **15 分钟为一个计数窗**；流量计数精度期望 ±5%~10%；计数员每 2h 休息 10~15min
- **中国《公路交通情况调查统计报表制度》（国统办函〔2017〕385号）**：**人工观测每小时误差 <5%**、全自动 <2%；昼夜 <2000 辆方可人工记录——此口径可与本项目对齐
- **GB/T 24726-2021《交通信息采集 视频交通流检测器》**：现行国标（2022-05-01 实施），车流量精度 ≥95%（数值待核标准原文）——**作为视频统计口径的国标验收依据**

### 4.2 最小可行规程（10~15 分钟对账，建议稿）

1. **人员**：断面 2 人（主计+复核）＋视频侧 1 人同时窗统计
2. **时窗**：15 分钟/窗、至少 3 窗（或早/平/晚各 1 窗），窗间休 5 分钟
3. **记录字段**：方向、车道、分车型（car/van/bus/truck）、窗号、计数员、异常备注
4. **比对口径**：同时窗、同断面、同车型集合；视频侧计数线固定、跨线判定用框底边中心
5. **允许误差**：总流量相对偏差 **≤5%**（对齐国标 ≥95% 与人工 <5%）；分车型 **≤10%**（对齐 FHWA）；不一致先查时窗边界/漏检/遮挡，**不改视频原始输出**
6. **留证**：同时窗录像留存、允许第三方复核；歧义车单独登记用于修口径而非改数字

## 5. 自采 vs 公开：决策建议

1. **首选「1 自采 + 5 公开」混合**：自采 1 段与目标断面同机位的场景（真值控制点 + 10~15 分钟对账录像），打通「标定→计数→对账」全链路；其余 5 段用公开集做规模化验证。**所有 ≤3px 类精度断言必须在自采真实机位上验收**
2. 完全不能自采时：UA-DETRAC（检测/计数/微调）+ NGSIM（轨迹真值对账/标定复现）+ BrnoCompSpeed（标定+测距复现）
3. 可商用路径：改用自采或 Pixabay/Pexels 可商用素材；车牌可见性建议模糊化
4. 风险：①UA-DETRAC 靠镜像下载，协议以官方为准；②GRAM-RTM 禁训练；③AI City 注册制不排关键路径
