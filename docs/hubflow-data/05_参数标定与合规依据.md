# 参数标定依据与合规条款（一期标定起点）

> 性质：**数据收集文档**。为 HubFlow 全部【待标定】参数提供权威出处/经验区间/标定方法；为视频链路与地图使用提供合规依据。
> 版本：v1.0（2026-10-10）。可信度：高（官方原文/规范/同行评审）/ 中（权威二手、学位论文）/ 低（社区经验）。

## 1. 交通工程参数（经验值）

| 参数 | 权威出处 | 经验值/要点 | HubFlow 适用建议 |
|---|---|---|---|
| **BPR α、β（美国标准）** | BPR *Traffic Assignment Manual* (1964)；MWCOG《Revisiting the BPR Function》 | 原始值 **α=0.15、β=4**（口径：城际公路、LOS C 容量）；MWCOG：α=0.15@LOS C ≈ α=0.4@LOS E；freeway α 0.1~1.2/β 4~9、arterial α 0.15~1.0/β 2~6 | 作为**标定搜索区间中心与对照基准**；必须先声明 c 的口径（LOS C vs 设计通行能力），不同口径 α 不可直接比 |
| **BPR α、β（中国城市道路）** | 张巧（中南大学 2013，宁波实测 VISSIM）；邵长桥 2023；国内多篇综述 | 宁波：主干道 **α=0.95 β=2.53**、次干道 α=1.27 β=2.19、支路 α=1.71 β=1.97；普遍结论：**中国城市道路 β 明显小于 4（1.9~2.9）、α 明显大于 0.15（0.9~1.7）**（信号密集+混合交通） | **不建议直接沿用 0.15/4**；以「α≈1.0、β≈2.5」为城市道路中值先验，**标定区间 α∈[0.6,1.7]、β∈[2,2.9]，按道路等级分组**；总搜索区间 α∈[0.15,1.7]、β∈[2,4] |
| 饱和度 x 口径 | 通行做法 + CJJ 37-2012 | v=高峰小时流量（pcu/h）、c=通行能力；**口径决定 α 数值** | 文档写死口径：「高峰小时到达率折算 pcu / 该路段设计通行能力」；敏感性分析把"基本 vs 设计通行能力"作为情景档 |
| **饱和度安全阈值 0.8~0.9** | HCM 6th/7th（LOS 表）；中国《城市交通管理指南》四级 V/C；日本道路服务水平 | HCM v/c 分界：C/D=0.75、**D/E=0.9**、E/F=1.0（v/c>1 强制 F）；中国四级：≤0.8 自由流、**≤0.9 稳定流**、≤1.0 不稳定；部分城市路段 C 级 ≤0.75、交叉口 D 级 ≤0.90 | **默认中心 0.85，敏感性区间 0.80~0.90**；区分"路段口径"与"交叉口口径" |
| 冲击波/消散时间（T_d 依据） | 冲击波理论（JTTE 期刊论文、TU Delft/Cairo 讲义） | 波速 **u_w=Δq/Δk**；排队形成波 u₁、消散波 u₂；最大排队 **Q=t₁·u₁**；**消散时间 t₂=Q/(u₂−u₁)**；等价近似：t≈排队量/(c−λ) | T_d 默认实现用 t₂=Q/(u₂−u₁)（q₃ 取通行能力 c、k_j 阻塞密度需本地标定）；队列论近似做 sanity check |
| **通行能力基准（城市道路单车道）** | CJJ 37-2012 表 4.2.2/4.3.2 | 其他等级道路（60/50/40km/h）：基本 1800/1700/1650、设计 1400/1350/1300 pcu/h；分类系数 A_c=0.8；多车道折减 1/0.85/0.75/0.65 | 主干道单车道 c 取两档情景：**设计 1300~1400** 与 **基本 1650~1800**；枢纽周边再乘交叉口折减 |
| 快速路/匝道/交织区 | CJJ 129-2009；HCM 7th | CJJ 129：设计 2000/1800/1400（100/80/60km/h）、**三级服务水平 v/c≤0.83**；HCM：饱和流率 s₀=1900 pc/h/ln（城市人口≥25万）；交织区容量取「密度约束」与「2400/VR」较小者 | 匝道/交织区用 HCM 双层公式；国内口径用 CJJ 129「≤0.83」作设计上限；两者互为敏感性上下界 |
| **LOS 延误判据（对照 30s）** | HCM 信号交叉口控制延误：A≤10、B≤20、**C≤35、D≤55**、E≤80、F>80 s/veh | LOS E 常被视为可接受延误上限 | 「新增延误≤30s」落在 **LOS C/D 区间**内——可表述为"不把任何车辆推过 D 级下限"的近似定性依据 |

## 2. 运筹/调度约束参数（依据）

| 参数 | 权威出处 | 要点 | 建议 |
|---|---|---|---|
| **新增延误 ≤30s（不伤害约束）** | Jahn et al. *System-Optimal Routing with User Constraints*, Operations Research 2005（CSO）；Van Vuren TRR 1306 (1991)；Leeds ITS WP319 | CSO 用**容差因子 φ** 约束路径不超过最短路 φ 倍；低装备率（≤10%）SO 式引导使被引导车最多 +5% 行程时间——**无约束 SO 会损害低渗透率/未引导车辆** | 形式化为 CSO 容差：`min{绝对30s, 相对+5%~10%}`；**30s 绝对值标注"工程选择值"**，依据=距 LOS D/E 边界余量 + CSO 容差量级 |
| **租约 90s** | TomTom Navigation SDK（replanRouteInterval 默认 5min）；TomTom Traffic Model ID 每分钟更新、有效期 2min；HERE Flow 1min/incident 2min | 商业交通数据鲜度窗口 **1~2 分钟** | 90s ≈ 数据刷新周期（60s）的 1.5 倍、大于决策闭环时长——**经验起点**；最终用仿真网格 {30,60,90,120,180}s 定标 |
| **60s 检查 / 每车最多 2 次** | 滞回（hysteresis）工程指南：双阈值+最短保持时间防振荡；Gayah & Daganzo 2011（MFD 滞回）；route-swapping DUE 文献 | 标准防振荡手段=**双阈值+最小保持时间+频次上限**；Waze 惯例：每 2~5min 重算、新路线快 3~5min 才切换（最小改善阈值双门限） | 「60s 检查」对齐数据刷新周期；「最多 2 次」用滞回理论背书，数值列入自标定（周期 {30,60,120} × 上限 {1,2,3} 网格） |

## 3. 合规条款（中国法口径，逐条可引用）

| 条款 | 出处 | 要点 | 适用建议 |
|---|---|---|---|
| **PIPL 匿名化/去标识化** | 《个人信息保护法》（2021-11-01 施行）第 4/73 条 | 个人信息"**不包括匿名化处理后的信息**"；去标识化（仍属个人信息）vs 匿名化（**无法识别且不能复原**）；第 28 条：敏感个人信息含生物识别、**行踪轨迹** | 写死口径：去标识化≠豁免；涉车牌/人脸/轨迹要么**匿名化（不可复原）**要么落实单独同意 |
| **PIPL 第 26 条（公共场所图像专条）** | PIPL 第 26 条 | 公共场所图像采集"**只能用于维护公共安全的目的，不得用于其他目的；取得个人单独同意的除外**" | 若接入公共视频用于**疏导运营**（非公共安全）需单独同意或**改为匿名化统计**——架构级决策点 |
| **GB/T 35273-2020** | 个人信息安全规范 5.4(c)/6.3(b)(c) | 生物识别信息**分开存储、原则上不存原始图像**（可只存摘要/终端内使用/用后即删） | 与"只数车不认车"直接呼应：**不存原始图像、终端侧处理、只留摘要/计数** |
| **车牌是否个人信息（司法口径）** | 北京海淀法院案（2014）；上海宝山 2025 案（车牌+位置+时间=**行踪轨迹**，敏感个人信息）；两高刑案解释（行踪轨迹 50 条入罪） | **单独车牌一般不构成个人信息；车牌+位置+时间 = 敏感个人信息** | **最强警示：杜绝车牌入库**——"只数车不认车"不只是隐私优化，是规避合规风险的架构选择 |
| **「只数车不认车」的官方路径** | 《汽车数据安全管理若干规定（试行）》（2021-10-01 施行）第 3/6/8 条 | 车外视频含人脸/车牌属"重要数据"；鼓励**默认不收集**；第 8 条：应"**匿名化处理，包括删除含有能够识别自然人的画面，或者对画面中的人脸信息等进行局部轮廓化处理**" | 把"只数车不认车"升格表述为**符合第 8 条匿名化路径**的方案（而非"惯例"） |
| **交通数据脱敏标准** | JT/T 1480-2023《交通运输数据脱敏指南》（2024-03-01 实施） | 5 类脱敏技术（假名化/抑制/泛化/扰乱/加密）+ 7 步流程 | 脱敏方案直接引用该标准 |
| **公共安全视频新规** | 《公共安全视频图像信息系统管理条例》（国务院令 799 号，**2025-04-01 施行**）第 17/22 条 | 第 22 条原文：公开传播须对"**人脸、机动车号牌等敏感个人信息**"采取严格保护；第 17 条：保存**不少于 30 日**、到期删除；第 14 条：投用 30 日内公安备案 | 官方明文把**机动车号牌列为敏感个人信息**（公开传播场景）——文档强引用 |
| **人脸识别专项（2025）** | 《人脸识别技术应用安全管理办法》（**2025-06-01 施行**）第 10/13/15 条 | 有其他验证方式时**不得将人脸识别作为唯一方式**；存储达 **10 万人**须 30 工作日内省级网信备案 | 明文"不做人脸识别"；列红线 |
| **高德开放平台 ToS** | developer.amap.com/pages/terms/（已核实抓取） | 3.5 禁"存储、缓存或抓取"；4.12.3 禁"爬取、预读取、存储、缓存、截图"；4.12.4 禁"脱离本服务单独使用"；**3.4 车载场景与模型训练需另行许可**；7.7 须标注"高德地图" | **仅在线实时调用+带标识展示+零持久化**是唯一稳妥路径；任何缓存/训练须商务书面授权 |
| **百度地图开放平台 ToS** | lbsyun.baidu.com（已核实抓取） | 2.2 只可展示官方开放功能结果；3.3.2(ii)/3.3.3 禁"存储、缓存、预读取、脱离服务展示" | 与高德互为交叉验证，并排列出条款号 |

## 4. 仍无公开依据、必须仿真自标定的参数清单

| 参数 | 为何无依据 | 自标定方法 |
|---|---|---|
| 新增延误 30s 具体阈值 | 文献只有 CSO 容差因子等相对口径 | 网格 {10,20,30,60}s 敏感性 + 专家输入（运管/交警）；文档同时给相对表达（≤UE+5%/+10%） |
| 租约 90s 精确值 | 商业产品实现专有 | 网格 {30,60,90,120,180}s，统计租约过期率/重复计算率/建议一致性 |
| 60s 检查 + 每车 2 次 | 无直接文献值 | 网格 {30,60,120}s × {1,2,3}，看"路线抖动率"与收益曲线；双阈值实现滞回 |
| T_d 判定阈值（多长算消散） | 运营 KPI 选择 | 冲击波解析式给 t₂ 基线 → 仿真校准 k_j/q₃ → 现场录像验证 P85/P95 |
| 站点 BPR α β 本地值 | 宁波等个案不可移植 | 对数线性回归 `ln(t/t₀−1)=lnα+β·ln(v/c)`（卡口/浮动车数据按等级分组）；数据不足用 SUMO 校准 |
| 饱和度阈值 0.80/0.85/0.90 | 大范围规范口径未含"列车到发脉冲" | 阈值扫描 {0.80,0.85,0.90}，响应=溢出次数/平均延误/触发次数；含脉冲剖面仿真 |
| 司机遵从率 | 欧美 50~81%，中国高铁站无数据 | 问卷 SP + 仿真扫描 50~81%（先验中值 65%）；后续 A/B 实测修正 |
| 站外排队释放率 μ | 站点几何/配时特有 | 视频计数拟合 M/M/1；与冲击波 u₂ 互验 |
| 多目标权重 | 价值判断无规范 | 帕累托前沿（NSGA-II）+ 专家 AHP |
| 高德/百度数据缓存 | 无公开许可口径 | 不作自标定——在线调用+零持久化；缓存走商务协议 |

## 5. 结论性提示

1. **BPR 双轨表述**：美国标准值（0.15/4）作基准、国内标定值（α≈1.0/β≈2.5）作先验，搜索区间 α∈[0.15,1.7]、β∈[2,4]。
2. **30s/90s/60s/2 次四个数**：概念均有"同类设定族"依据（CSO 容差、数据鲜度、滞回保持时间、Waze 最小改善阈值），但**数值本身为工程选择值，全部列入自标定清单**。
3. **合规三根强引用**：PIPL 第 26 条（公共场所图像仅限公共安全）、《公共安全视频图像信息系统管理条例》第 22 条（车牌=敏感个人信息）、汽车数据规定第 8 条（官方匿名化路径）——直接支撑"只数车不认车"叙述；高德/百度 ToS 已双源核实。
4. 待人工复核：上海宝山 2025 案裁判文号、Waze 2.5min 口径、HERE 刷新频率、人脸识别办法原文链接。
