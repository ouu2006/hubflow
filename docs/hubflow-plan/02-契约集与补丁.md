> 基线：上游 [`../数据契约.md`](../数据契约.md) **v2.0**（冻结 2026-10-10；字段裁定人=开发B）。
> 性质：**v2.1 补丁建议**——按上游变更流程并入（当天 Issue、B 裁定、升版本号）；**并入前以 v2.0 为准**。
> 配套铁律：**每份契约必须配三件**——金样例文件（1 好 + 1 坏）、pydantic schema、一键校验脚本。这是弱编码任务自检与独立验收（任务池系列 Q，回避规则）的机器判卷，缺件视为契约未完成。

## 补丁 P1：`detectors.raw` 观测能力与逐指标有效性（修"E1 不足"）

v2.0 的 `segments` 四指标隐含要求 L2 提供队长/密度/消散，但 E1 只有断面过车数与速度（空路与完全停滞都可能是零过车）。补丁不指定实现（E1+E2 还是 TraCI 车辆聚合由开发A 自设计），只规定**必须可观测**：

```json
{
  "sim_ts": 3720.5, "source": "twin", "schema": "detectors.raw.v2.1",
  "detectors": [{
    "id": "D-07", "segment_id": "SEG-001", "sumo_edge_id": "E-012",
    "direction": "inbound", "lane_ids": ["E-012_0", "E-012_1"], "role": "boundary",
    "window": {"start": 3615, "end": 3735},
    "counts": {"n_veh": 42, "pcu": 46.5, "valid": true, "counting_semantics": "full_pass"},
    "speed": {"value_kmh": 21.3, "agg_method": "harmonic", "n_samples": 40, "valid": true},
    "queue": {"length_m": 55.0, "n_veh": 12, "state": "dissipating", "valid": true},
    "zone": {"n_veh": 15, "covered_len_m": 120, "valid": true},
    "confidence": 0.91
  }]
}
```

硬规则：**每指标独立 `valid`**（"计数有效但速度无样本"必须可表达）；`miss` 只表示整检测器缺测，不顶替逐指标有效性；`queue.state` ∈ {forming, dissipating, static, none}。

## 补丁 P2：断面适配契约（修"视频轨迹→断面无定义"）

1. **新增 L2 交付物「断面适配器」**：视频 ROI/计数线 ↔ `segment_id` ↔ `sumo_edge_id` ↔ 车道 的映射表，落 `points.json` 扩展字段（`video_roi`、`direction`、`lane_ids`）。
2. **计数语义双侧登记**：twin 侧 = 完全通过（`nVehContrib` 口径，`counting_semantics:"full_pass"`）；video 侧 = 框底边中心跨线（`"bottom_center_crossing"`，与对账规程一致）。同字段名不同语义必须在契约里显式声明。
3. **PCU 折算系数表进 L1**（GA 802 口径 car/van/bus/truck = 1/1.5/3/4），双源统一折算后再入 `counts.pcu`。
4. **速度口径登记**：`agg_method` 必填（调和/算术），双源各自声明。

## 补丁 P3：时间映射（修"媒体时间≠仿真时间"）

```text
t_sim = t0 + rate × t_media        （t0/rate 进点位表或 scenarios.json）
```

| 字段 | 定义 | 规则 |
|---|---|---|
| `sim_ts` | 权威仿真调度时钟（全系统唯一） | 一切消费以它为准 |
| `media_ts` | 视频内时间（源=video 时必填） | `CAP_PROP_POS_MSEC` 后端相关，须验证，不得假定帧号×FPS 恒准 |
| `processed_at` | 实际处理完成时间 | 仅记 `latency_ms`，**不污染 age** |
| `data_age_s` | `sim_ts − 映射后观测时刻` | 门控 `age ≤ 120s` 以此计算 |

消费规则：只消费**窗口闭合且已到期**的观测；EOF/缺帧/迟到一律显式 `miss:true` 并落日志，禁止静默跳过或外推。

## 补丁 P4：评测计数与快照（配合 01§3 评测协议）

- `assimilation_state.json` 增加**累计** `inserted_total / removed_total`（按断面）；
- episode 实验日志增加四计数：`inserted / removed / not_entered / completed`；
- 预约簿每拍落盘快照（`reserved[seg][slot]` 随 episode 归档），保证 TC-13 回放可复算决策。

## 金样例与校验脚本规范

| 项 | 要求 |
|---|---|
| 样例 | `contracts/samples/` 下每契约 1 好 1 坏；坏样例必须能让校验器报错 |
| schema | `tools/contracts/` pydantic 模型，owner=B 唯一维护 |
| 校验 | `tools/validate_contracts.py <file>` 退出码 0/1；进 CI |
| 用途 | 弱编码任务自检（三 prerequisite 之一）；系列 Q 独立验收的判卷器（认领者≠产物生产者）；边界探测（越契约的 PR 在 CI 就红） |

## 变更流程（沿用上游，不另起炉灶）

改字段：当天 Issue → **B 裁定** → 升版本号 → 更新金样例与 schema。字段语义级变更建议 A/B/C 三签。二期只换数据源、不改形状的纪律不变。
