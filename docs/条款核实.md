## 0. 一页结论（先看这个）

### 0.1 三条红线（**不碰就不会出事**）

| # | 红线 | 依据（已核实原文） | 触碰后果 |
|---|---|---|---|
| **红线 1** | **不得离线缓存、批量下载、预取高德 / 百度的地图瓦片与任何服务数据**；也不得用官方 OSM 瓦片服务器（`tile.openstreetmap.org`）做离线包 | 高德协议 3.5、4.12.3、7.3；百度条款 3.3.2(ii)、3.3.3；OSM 瓦片使用政策第 4 节 | 高德违约**违约金 2000 万元**（高德协议 10.1）；百度可封禁 AK、终止服务 |
| **红线 2** | **不得把高德 / 百度的数据（底图截图、POI、路况、路径规划结果）落库、落盘、二次加工成衍生数据或用于模型训练** | 高德协议 3.4、3.5、4.12.7、4.12.8；百度条款 3.3.4、6.3 | 同上；且衍生数据一旦发布可能同时侵犯两家权利 |
| **红线 3** | **对外公开发布地图（含管理端大屏、演示物料）必须①保留审图号与版权标识、②依法送审取得审图号、③按 ODbL 对 OSM 数据署名并共享相同** | 高德协议 4.10.6、7.7；百度条款 3.5、6.6；ODbL 4.2 / 4.3 / 4.4 / 4.6 | 违反《测绘法》《地图管理条例》，属行政责任；ODbL 违约自动终止许可（ODbL 9.1） |

### 0.3 商用授权未到位时的降级方案（**三档，按顺序退**）

| 档 | 触发条件 | 做法 | 路网是否受影响 |
|---|---|---|---|
| **A 档（推荐，一期默认）** | 高德 / 百度 Key 已申请，但**未购买技术服务许可**（非商业、非投标、非后台管理系统） | **仅在线调用底图做人工核对与内部演示**；不缓存、不落盘、不对外发布地图截图；管理端地图标注「底图 © 高德地图」并保留审图号 | **不受影响**，路网全走 OSM + `netconvert` |
| **B 档** | 条款核实认为连在线调用都超范围（如被认定为「后台管理系统」或「项目投标」，见高德 3.2.1 / 百度 2.3） | **底图降级为静态截图**，仅用于 池·S 打标签与 T2 核对；管理端不渲染第三方底图，改为渲染**自绘的 OSM 派生路网**（自带 ODbL 署名） | **不受影响** |
| **C 档** | 静态截图也不允许（最保守） | **仅内部演示、不对外发布**；对外物料只用自绘路网示意图，不使用任何第三方底图 | **不受影响** |

> **一句话**：因为 D7 已经把路网主路径放在 **OSM + netconvert**，**地图 API 条款收紧不会阻塞一期开工**——这正是 D7 的价值。受影响的是「底图好不好看」和「能不能对外发截图」，不是「路网能不能建」。
