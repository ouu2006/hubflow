## 口径自查

- 全部画面 `is_simulated: true`（页面「数据来源」卡片显式列出），顶栏 **M1-7 角标**逐张可见；
- 用户可见文案**不出现**「实测 / 实时 / 现场」（唯一豁免是页面停靠纪律里手册原文的「请服从现场指挥」）；
- 等级 / 指数标注为「**演示数据（模拟）**」，几何标注为「几何取自 OSM（真值）」；
- 车辆位置标注为「**站点包 Z 给定（不做定位）**」，本单**不发任何定位请求**（TC-05 App 侧）；
- **「全览」保留**（`02b`）；**「生成路线」不存在**——页面没有绘制 / 生成路线 / 清除，也没有任何到第三方路由服务的请求。

## 复现这几张图

```bash
python -m http.server 8123 --bind 127.0.0.1          # 仓库根起静态服务
# 浏览器打开 http://127.0.0.1:8123/work/frontend/app-html/index.html
# 控制台可直接复核（与截图同时刻的值）：
HUBFLOW_APP.segmentsInView().length      // 全览后应为 21（放大后 < 21）
HUBFLOW_APP.paintOf().filter(p => p.level).length   // 5
HUBFLOW_APP.paintOf().filter(p => !p.level).length  // 16
HUBFLOW_APP.cameraMarkers()              // 6
```
