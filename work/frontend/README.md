# 前端

> **产出**：管理端页面 + 司机端鸿蒙 App
> **消费方**：管理者、司机

## 负责什么

| 端 | 技术 | 复用情况 |
|---|---|---|
| 管理端 | **Vue 3 + Vite + Element Plus** | 复用上游 `harness-core/ui-vue` 工程，新增交通页面 |
| 司机端 | **鸿蒙（ArkTS / DevEco Studio）** | 新建；**全程由 AI 辅助开发** |

## 管理端要做的页面

| 页面 | 优先级 | 内容 |
|---|---|---|
| 态势总览 | P0 | 路网图 + 路段四级着色 + 实时指标叠加 |
| 拥挤度热力 | P0 | 四级色 + 图例 + 更新时间戳 |
| 检测画面 | P0 | 视频列表、实时/回放、检测框与轨迹 ID、指标浮层 |
| 事件告警列表 | P0 | 等级、路段、时间、指标依据、状态 |
| 分流方案下发 | P0 | 系统建议 + 人工可编辑 + 回执 |
| 处置回写 | P0 | 认领人、动作、结果四选一、时间戳 |
| 效果对比报表 | P0 | 处置前后四项指标对比 |
| 阈值配置 | P1 | 分级阈值与权重，变更留痕 |

## 司机端要做的页面

| 页面 | 优先级 | 内容 |
|---|---|---|
| 当前建议 | P0 | 推荐路线 + **至少两条备选** + 预计耗时 + 差异原因 |
| 落客 / 候客指引 | P0 | 停靠点类型、位置、预计等待（或步行接驳时长） |
| **离站路线** | P0 | 送完人之后怎么走（**本项目独有**） |
| 我的行程 | P1 | 如实标注"未采纳推荐" |
| 设置 | P1 | 定位权限、通知权限、身份选择（出租车 / 私家车） |

## 三条硬性要求

1. **三重编码**：**颜色 + 图标 + 文字必须同时出现**，关掉颜色也要能区分四级。缺一视为不通过。
2. **数据不可用显示灰色**，**绝不显示成蓝色**——"没数据"不能被读成"很通畅"。
3. **不强制、不反复弹窗**；应急状态下**停止路线引导**，替换为"请服从现场指挥"（优先级高于一切推荐）。
