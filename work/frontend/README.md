# work/frontend · 接口与双端（开发C）

> **产出**：**管理端页面**（Vue）+ **司机端鸿蒙 App**
> **消费方**：管理者、司机
> **同目录职责**：本目录 = `work/frontend/`；接口层与总装脚本在 [`../assembly/`](../assembly/)（同一人负责）

## 一、负责什么

| 端 | 技术 | 复用情况 | 期次 |
|---|---|---|---|
| 管理端 | **Vue 3 + Vite + Element Plus** | 复用上游 `harness-core/ui-vue` 工程，新增交通页面 | 一期 |
| 司机端 | **鸿蒙（ArkTS / DevEco Studio）** | 新建；**全程由 AI 辅助开发** | 一期只做 P0 四页 |
| App 真实定位上报 | 鸿蒙定位能力 + 后端 `locate` | 二期 | 二期 |

> **一期数据来自两条链路**（D1′）：页面上的每一个数（车流量、车速、等级、车辆位置）都来自 `work/twin/`、`work/perception/` 与 `work/engine/` 的快照文件，**`is_simulated` 恒为 `true`**；`segments` 的 `source` **一期取 `"video"` 与 `"twin"` 两个值**——**视频感知链路**（YOLO 跑 6 段真实样本视频）与**孪生链路**（虚拟检测器）**必须能在同一路段并排展示**（**TC-19**）。**一期没有视频画面可看**——视频链路的产物是**指标快照**而不是视频流，"检测画面"页（视频列表 / 实时回放 / 检测框叠加）归二期。

| **数据同化状态** | **P0** | **某断面是否正在被同化**（开 / 关状态与门控原因：置信度不足 / 数据过旧 / 偏差超标熔断），读 `/api/traffic/assimilation` | 一期 |

## 三、司机端要做的页面

| 页面 | 优先级 | 内容 | 期次 |
|---|---|---|---|
| 当前建议 | P0 | 推荐路线 + **至少两条备选** + 预计耗时 + 差异原因（`why`）+ **前后车协同说明**（"不会让已在你前面的车变慢"） | 一期 |
| 落客 / 候客指引 | P0 | 停靠点类型、位置、预计等待（或步行接驳时长） | 一期 |
| **离站路线** | P0 | 送完人之后怎么走（**本项目独有**） | 一期 |
| 我的行程 | P1 | 如实标注"未采纳推荐" | 一期 |
| 设置 | P1 | **一期：选择绑定的演示车**；二期：定位权限、通知权限、身份选择（出租车 / 私家车） | 两期 |

### 3.1 一期：**绑定演示车**

| 项 | 口径 |
|---|---|
| 数据来源 | `GET /api/traffic/vehicles`（读 `vehicles.json`，**孪生内部数据**） |
| 绑定规则 | App 一期**只绑一辆"演示车"**——`is_demo_bound: true` 的那一辆，**同一时刻最多一辆** |
| 为什么要绑 | 一期车辆就在孪生里，**没有真实定位可上报**；绑一辆车让 App 能显示"它的位置、推荐路线、备选、离站路线"，证明**双端同源**（M1-5） |
| 位置从哪来 | **后端直接给**（孪生真值），App **不做任何定位请求** |
| 口径纪律 | 一期 App **不得**声称"已接入真实定位"；`GET /api/traffic/vehicles` **二期下线** |

### 3.2 二期：真实定位上报（**一期只留接口位，不实现**）

| 项 | 口径 |
|---|---|
| 上报频率 | 进入站前围栏后 **每 5–10 秒上报一次** |
| 权限 | **用户主动同意**才开启定位；**首次进入围栏时请求**，不在启动时弹 |
| 上报内容 | 位置（统一转 **WGS-84**）+ 航向 + 时间戳 + `session_id`（**匿名会话号，不含身份**） |
| 后端处理 | `POST /api/traffic/locate` → 地图匹配 → 路段 + 路段内位置 + `match_confidence` |
| 低置信度 | `match_confidence < 0.6`【待标定】时**不用于重新规划**，提示"定位不稳定，请确认所在道路" |
| 隐私告知文案（**必须原样出现**） | 「**本 App 仅在您进入站前区域后使用您的定位，用于判断您所在的道路并为您匹配路线。定位信息只用于您本人的本次行程，行程结束后即删除；不会记录您的车牌或身份，也不会与路侧摄像头数据关联。您可随时在设置中关闭定位。**」 |
| 拒绝定位 → 降级 | **流程不中断**：降级为「**手动选所在道路 / 只看路况**」，仍可看推荐与路况，**不反复弹窗**（TC-05） |
| 存储 | **只保留本次会话，行程结束即删**；不入库、不给其他司机看 |

## 四、三条硬性要求（**两期都适用**）

1. **三重编码**：**颜色 + 图标 + 文字必须同时出现**，关掉颜色也要能区分四级。缺一视为不通过。
2. **数据不可用显示灰色**，**绝不显示成蓝色**——"没数据"不能被读成"很通畅"。一期判级的可用性门会输出"不可用"，页面必须有这个分支。
3. **不强制、不反复弹窗**；**应急状态下停止路线引导**，替换为"请服从现场指挥"（优先级高于一切推荐）。
