> **演示数据（模拟）· 一期演示环境**：本文档描述的接口层 `work/assembly/traffic.py` 是**演示环境**的包装层，

> 导航软件对接、真实下发通道、真实天气/列车数据均**未接入**（一期只定义形状，见第 9 节）。

## 1. 基础约定

| 项 | 约定 |
|---|---|
| 前缀 | 全部业务端点都在 `/api/traffic/*` 下；**一期唯一的业务入口**（`/api/perception/*` 只属感知演示面，不参与业务契约） |
| 方法 | 读只用 `GET`；写只用 `POST`（无 PUT/DELETE/PATCH） |
| 请求体 | `Content-Type: application/json; charset=utf-8`；`GET` 无请求体 |
| 响应体 | JSON（`text/event-stream` 除外，见第 8 节 SSE） |
| **信封 `is_simulated`** | **每一个**响应（含 4xx/5xx）顶层都带 `"is_simulated": true`；失败响应不含数值字段 |
| `note` | 可选的人话说明：降级原因 / 演示态口径 / 接口层不代算的声明。**前端不依赖 note 做逻辑**，它给人看 |
| 时间 | 数据快照时间 `ts` 用带时区 ISO8601（如 `2026-10-13T18:42:55+08:00`）；留痕时间（回执 / 审计）用 `YYYY-MM-DD HH:MM:SS`（本地时区） |
| 响应头 | `X-Traffic-Data-Source`：本次数据取自哪一层（如 `perception.video+twin.latest` / `stations.baseline` / `engine.routes.real` / `dispatch-store`）；`Cache-Control: no-store`（快照接口不缓存） |
| 段号命名空间 | **`SZ-###` = 站点 Z 真网（61 段，IKMS11）**；**`SEG-###` = 7 节点样例网**。两套产物分开目录、**不混进同一份响应**；路线响应带 `segment_namespaces` / `segments_not_in_snapshot` 如实列差异 |
| 未匹配路径 / 方法 | 一律 `404 {"code": "NOT_FOUND"}`（照搬 mock 的纪律：不静默吞路径） |

### 1.1 数据源与降级（接口层的定位）

接口层**只读快照、不写快照、不重算判级**。数据源按优先级回落，文件缺失**不报 500**，而是下一层或空壳 + `note`：

| 优先级 | 数据源 | 说明 |
|---|---|---|
| ① | `work/perception/out/latest/segments_video.json` | 视频感知链路产物（`source: "video"`，样本视频回放，非本站现场） |
| ② | `work/twin/out/latest/segments_twin.json`（回退 `work/twin/out/segments.json`） | 孪生链路产物（`source: "twin"`，虚拟检测器） |
| ③ | `work/engine/out/real/routes.json`（回退 `work/engine/out/routes.json`） | 决策引擎路线（真网优先、样例回退）；只服务 route/recommend / locate |
| ④ | `stations/*.json` | 站点包静态基线（无运行指标时：level=0「数据不可用」，不编数） |

## 2. 鉴权形状（**一期无鉴权**，只定义二期形状）

> 手册 §13.3 口径：**鉴权 = 平台级密钥（一期只定义形状与字段，不发放真实密钥）**；频率限制**一期只定义字段、不做限流实现**。

| 期次 | 实际行为 | 说明 |
|---|---|---|
| **一期（现状）** | **无鉴权、无密钥、无限流** | 服务只绑 `127.0.0.1`（回环），只给本机演示页面 / 脚本调用；**不得**把 :8000 暴露到公网或局域网 |
| 二期（形状预留） | 请求头 `Authorization: Bearer <platform-key>` | 平台级密钥由平台方发放与轮换；密钥只进本地 `.env`，**不进仓库**；按调用方配额限流（字段预留，未实现） |

- 一期**没有**用户登录 / 账号 / Token；所有端点对能访问 `127.0.0.1:8000` 的进程开放（演示环境）。
- `session_id` 不是鉴权凭证，只是**匿名会话号**（不含身份），见第 3 节。

## 3. 围栏衔接（进入站前围栏前 / 离站后，手册第 13 章）

### 3.1 谁算哪一段

| 区段 | 谁负责算路 | 一期怎么演 |
|---|---|---|
| **围栏外**（高速出口 → 站区外围道路，几公里） | **导航软件（高德 / 百度）自己算**；本项目不重复造轮子、不拿它的数据 | 一期无真实导航对接：用孪生**边界车流**（F13 外围路网路况）代替来车节奏 |
| **围栏内**（站前区域，肇庆东半径 **500 m**，脚本自动推定） | **本引擎算**：落客 / 候客 / 蓄车 / 离站 / 前后车协同 | `route/recommend` 返回围栏内推荐 + 离站路线 |
| **衔接点** | 围栏边界上的**入口节点** | 导航把「当前位置 → 围栏入口」留在自己侧，把「入口 → 落客点 / 候客区 / 离站」交给本平台；界面拼成一条完整指引 |
| **谁调用** | 围栏外由 App / 前端**直连**高德官方 SDK/API；**后端不代理、不转发、不缓存**高德原始响应（合规红线，高德 4.12.4 / 4.12.9） | 一期只接收「围栏外路段 ETA」这一个结果值（预留字段，未实现） |

### 3.2 调用形态（二期对接时使用，一期可照此自测）

```text
导航软件判断车辆即将进入高铁站周边（地理围栏，建议半径 3 km【建议值】）
  → 越过围栏：POST /api/traffic/route/recommend
        请求：session_id（匿名会话号）+ location（当前位置）+ dest_type + driver_type/parking_mode（可选）
  → 本平台返回：arrival_route / departure_route / alternatives ≥2 / reservation / why / factors_note
  → 导航软件渲染进自己的界面，并把「是否采纳」匿名回传（二期）
```

- **进站前**：`POST /api/traffic/locate`（一期取孪生真值：`source: "twin"`、`match_confidence: 1.0`）→ 再 `route/recommend`。
- **离站后**：响应里的 `departure_route`（送完人之后怎么走）；二期只换「围栏外那一段」的数据来源，围栏内算法不变（D2 口径）。
- **合规边界**：返回内容只含**路段级匿名状态**，不含任何其他车辆的位置或身份；`session_id` 行程结束即删；**不做司机之间互通**（C 端只调聚合接口）。

### 4.2 路线 / 定位（POST）

| 端点 | 用途 | 备注 |
|---|---|---|
| `POST /api/traffic/route/recommend` | 请求推荐路线（契约 §二 响应体；含 `session_id` / `location`） | 真网产物优先、样例回退；缺产物 404 `ROUTE_UNAVAILABLE` |
| `POST /api/traffic/locate` | 定位 → 路段（一期取孪生真值，不做地图匹配） | 缺产物 404 `ROUTE_UNAVAILABLE` |

### 4.3 处置闭环（持久化写 + 读）

| 端点 | 用途 | 持久化 / 口径 |
|---|---|---|
| `POST /api/traffic/plan/dispatch` | 下发分流方案 → 回执（渠道 / 比例 / 操作者可选） | **JSON 文件仓** `work/assembly/data/dispatch.json`；重启不复位；同告警同渠道同比例重复下发幂等（`idempotent: true`） |
| `POST /api/traffic/plan/ack` | 处置回写（认领人 / 动作 / 结果四选一）→ 状态流转 | 同上；**无下发回执不可回写**（409 `ACK_NO_DISPATCH`）；终态不可翻转（409 `ALERT_TERMINAL`） |
| `POST /api/traffic/alerts/reset` | 演示复位：清运行态并重放 `seed_dispatch`，写一条 reset 审计 | 同上；`reset` / `--reset-state` 都留审计 |
| `GET /api/traffic/plan/audit` | **辅助端点（非契约）**：审计查询 `?limit=1..1000&alert_id=`；`total` 为未截断匹配总数 | `records` 含 `seq/at/action/alert_id/segment_id/channel/ratio_pct/operator/result/status_after` |
| `GET /api/traffic/alerts` | 读上面这份运行态（四态 + 渠道 / 时间 / 比例 / 回写留痕） | 与 dispatch/ack 同一份状态 |

> 写端点**恒带** `note` 说明「演示态、无真实下发通道」；渠道只是展示枚举（情报板 / 导航软件推送 / 现场调度 / 广播），
> 回执只是「已确认」的演示回执，**不得**说成已通知司机 / 情报板。

### 4.4 人工置位 / 场景注入（写，进程内存态）

| 端点 | 用途 | 备注 |
|---|---|---|
| `POST /api/traffic/factors` | 人工置位（F07 / F08 / F11，手册第 19 章） | 只登记因素状态；响应 `level_recomputed: false`（接口层不重算判级） |
| `POST /api/traffic/factors/reset` | 清空人工置位 | 幂等演示复位 |
| `POST /api/traffic/scenario` | 场景注入（F01 天气 / F02 昼夜 / F03 列车到发 / F10 时段） | 只改环境状态与 `derived_factors`；`effects` 如实为空（判级需感知层重算） |
| `POST /api/traffic/scenario/reset` | 清场景注入 | 幂等演示复位 |

> 这四类写端点与「处置闭环」是**两个口子**：处置闭环（dispatch/ack）落盘可查；人工置位 / 场景注入是进程内存演示态，**重启复位**。

## 6. 信封、数据源与降级速查

| 现象 | 含义 | 调用方应怎么处理 |
|---|---|---|
| `is_simulated: true` | 演示数据（模拟） | 页面 / 文档必须标「演示数据（模拟）」，不得称现场实测 |
| 响应头 `X-Traffic-Data-Source: stations.baseline` | 运行产物缺失，回落站点包静态基线（`level=0`） | 按「数据不可用」灰档展示；不要当「畅通」 |
| 记录里 `available: false` / `level: 0` / `data_age_s > 120` | 该路段数据不可用 / 陈旧（TC-11 / TC-06） | 只展示、不进入推荐计算 |
| 顶层 `note` | 降级 / 演示态说明 | 原样展示给演示观众（前端不依赖它做逻辑） |
| `persisted: true`（写端点） | 回执 / 留痕已落盘（重启不复位） | 可刷新 / 重启后重新 `GET /alerts` 对账 |
| `idempotent: true`（写端点） | 重复提交被识别为幂等回放（未写新审计） | 展示既有回执即可，不要重复记流水 |

## 7. 错误码表（与 `traffic.py` 实现一致）

| HTTP | code | 触发场景 | 备注 |
|---|---|---|---|
| 400 | `ACK_INVALID` | 回写参数不完整 / 结果不是四选一 | 结果枚举：已消除 / 已缓解 / 未改善 / 误报 |
| 400 | `DISPATCH_INVALID` | 下发参数不完整 / 分流比例不在 (0,100] | |
| 400 | `ALERT_SEGMENT_MISMATCH` | 请求的 `segment_id` 与告警自带路段不一致 | |
| 400 | `PREDICT_INVALID` | `/predict` 缺 `segment_id` 或 `h` 非数值 | |
| 400 | `CI_HISTORY_INVALID` | `/ci-history` 缺 `segment_id` | |
| 400 | `FACTOR_INVALID` | 人工置位参数不完整 / 因素或目标不合法 | 只允许 F07 / F08 / F11 |
| 400 | `SCENARIO_INVALID` | 场景注入参数不合法 | |
| 404 | `SEGMENT_NOT_FOUND` | 路段不存在（详情 / 并排 / 预测 / CI 走势） | |
| 404 | `ALERT_NOT_FOUND` | 告警不存在（下发 / 回写） | 当前快照无 level≥3 路段时会出现 |
| 404 | `ROUTE_UNAVAILABLE` | 引擎路线产物缺失（recommend / locate） | 如实报缺，不代算 ETA |
| 404 | `NOT_FOUND` | 未匹配路径 / 未注册方法 | 统一信封 |
| 409 | `ALERT_TERMINAL` | 终态（已闭环 / 误报）再下发或换结果回写 | 同人同动作同结果幂等回放除外 |
| 409 | `ACK_NO_DISPATCH` | 无下发回执就回写 | TC-07 闭环顺序 |
| 422 | `BAD_REQUEST` | FastAPI 参数校验失败 | 统一信封 |
| 500 | `PERSIST_FAILED` | 处置运行态落盘失败（目录不可写等） | 内存与磁盘均保持旧状态 |
| 500 | `INTERNAL_ERROR` | 未预期异常 | 详见服务端日志 |

> 一期错误响应也恒带 `"is_simulated": true`；`note` 视场景附加。
> 代码里的 `NOT_IMPLEMENTED` / `NO_DATA` 是**预留常量**，当前没有端点会返回它们（如后续出现未实现 / 无数据端点会使用），不属于现行行为，故不列在上表。

## 8. 事件流（SSE）

```bash
curl -N http://127.0.0.1:8000/api/traffic/stream
```

```text
event: traffic_snapshot
data: {"ts": "2026-10-13T18:42:55+08:00", "is_simulated": true, "note": "快照刷新事件（接口层只读快照）；收到后请重新拉取快照"}
```

- 事件名 `traffic_snapshot`（契约约定：**只新增事件名、不改既有事件名**）；
- 每 **2 s** 一帧，只作「快照已刷新」提示，页面收到后重新拉取快照；
- 无鉴权（一期回环）；断线由 `EventSource` 自动重连。

## 9. 演示环境声明（M1-7 / 口径红线）

1. **一期是演示环境**：所有数据 `is_simulated: true`，**无真实用户数据**、无真实账号体系、无真实下发通道（渠道只是展示枚举，回执只是「已确认」的演示回执）；
2. **视频链路是真实拍摄的样本视频**（非本站现场）经 YOLO 推理的结果；**站点几何来自 OSM**；**不得**说成「现场实测 / 实时」；
3. **围栏外导航对接**一期只定义形状（第 3 节），**未与高德 / 百度联调**；后端不代理、不转发、不缓存高德原始响应；
4. 外发材料 / 页面 / 本文档必须带「**演示数据（模拟）**」角标；**不得**出现「真实接入 / 现场实测 / 昇腾部署已验证」等表述；
5. 二期（真实导航对接、真实落库 openGauss、Atlas 部署）不在本接口文档承诺范围内。
