### 1.3 换机器怎么装（照抄这五步）

```bash
# ① 下载官方 win64 zip（约 177 MiB）到非系统盘
curl -L -o /d/_tmp_sumo/sumo-win64-1.28.0.zip https://sumo.dlr.de/releases/1.28.0/sumo-win64-1.28.0.zip

# ② 解压到目标目录（示例：D:\app\SUMO），保持 bin/ tools/ 的层级
unzip -q sumo-win64-1.28.0.zip -d /d/app/_sumo_extract
cp -r /d/app/_sumo_extract/sumo-win64-1.28.0/. /d/app/SUMO/

# ③ 设三个用户级环境变量（PowerShell，不需要管理员）
#    SUMO_HOME = D:\app\SUMO
#    PATH      追加 D:\app\SUMO\bin; D:\app\SUMO\tools
#    PYTHONPATH 追加 D:\app\SUMO\tools

# ④ 新开一个终端，验版本与 Python 侧可用性
sumo --version
netconvert --version
python -c "import traci, sumolib; print(sumolib.version._version)"

# ⑤ 跑官方示例（Hello SUMO，教程在 %SUMO_HOME%\docs\tutorial\hello\data）
cd <一个可写目录> && cp "$SUMO_HOME"/docs/tutorial/hello/data/* ./
sumo -c hello.sumocfg --tripinfo-output tripinfo.xml --summary-output summary.xml
```

> **四个坑**（本次实测踩到，写下来省下一个人的时间）：
> 1. **要版本别读 `traci.__version__`**：它返回的是**占位值** `'0.0.0'`（属性存在但没意义）。取版本用 `sumolib.__version__` 或 `sumolib.version._version`（本机均 = `'1.28.0'`），或看 `traci.constants.TRACI_VERSION`（本机 = `22`）。
> 2. **`sumo-gui` 截图不能只看退出码**：`traci.gui.screenshot()` 之后**必须再走一步仿真**（`simulationStep`）截图才真正落盘，否则命令返回成功而文件不存在——**与上游仓 `_write_frames()` 那个"假通过"是同一类问题**（[`现状核实.md`](现状核实.md) 第 4.3 节）。另外截图前要 `gui.setBoundary()` 把视图对准路网，否则截出来是空白画布（实测只 2~4 种颜色）。
> 3. **`libsumo` 只认 CPython 3.11**：包里的 `tools/libsumo/_libsumo.pyd` 依赖 `python311.dll`，用**系统 Python 3.12 导入会报 `ImportError: DLL load failed while importing _libsumo`**（不是装坏了）。要用 libsumo 就走**上游那个 3.11 venv**（实测可跑通仿真）。**本项目主路径是 TraCI，不依赖 libsumo**（手册 10.2 把 `TraCI vs libsumo` 列为"做法可自选"）。
> 4. **`calibrator` 的 `file=` 是输入不是输出**：XSD 里 `file` / `output` 是两个属性——**`file` 读路线文件，`output` 才是校准统计输出**。更关键的是**它必须能拿到"路线分布"**（`routeProbe` 或已有路线文件），否则报 `No valid routes in calibrator` 而**一辆车都不补**（本次实测：不挂 `routeProbe` 时 120 s 补 0 辆；挂上后同样 120 s **插入 41 辆**）。这直接影响手册 10.14 的数据同化实现，别以为是参数写错了。

### 1.4 功能完整性核对（本机实测清单）

**结论：项目一期要用的东西全都在**。标准包（EPL，本机装的这个）与 "all extras" 的区别，官方 Downloads 页的原话是：*"the **extra** build which contains **GPL code to support GeoTIFFs, shapefiles and 3D models**"*，Installing 页补一句 *"GPL, including **video encoding and 3D GUI** or **EPL without**"*。也就是 extras 多出来的是 **GeoTIFF / shapefile 读写、3D 模型与 3D GUI、视频编码**这几块，**它们带的 GPL 代码在商用集成分发时要避开**。

本项目**这几块一个都不用**：路网主路径是 **OSM → `netconvert`**（不是 shapefile 导入；项目文档里 grep 不到 `shapefile` / `GeoTIFF` / `.shp`）、手册风险表第 20 条明确"**不做 3D 孪生大屏**"、录屏用普通屏幕录制工具（不走 SUMO 内置编码）。所以**装标准包是正确选择，不是功能缺斤少两**。

### 1.6 一期怎么用（与本项目其它文件的接口）

- **一期主链路**：孪生由 SUMO 驱动（路网走 OSM + `netconvert`），自研司机行为体通过 **TraCI** 改路线 / 停靠 / 候客；虚拟检测器（E1 inductionLoop）出断面数；边界断面用 `<calibrator>` 做数据同化——**calibrator 只放边界 / 进口 edge，站内断面只放 E1**（依据 [`hubflow-data/03_技术事实_SUMO与数据同化.md`](../../docs/hubflow-data/03_技术事实_SUMO与数据同化.md) §3.6）。
- **路网产物**：`stations/sumo/*.net.xml` 归开发A（`netbuild.py` + `netedit`）；开发B 的 `map_ingest.py` **不重跑** `netconvert`。生成命令写 [`../../work/twin/README.md`](../../work/twin/README.md)。
- **一期不分发 SUMO 本体**：演示脚本 `demo.bat` / `run_all.py` 只**调用**已安装的 SUMO，**不打包、不复制**其可执行文件与 `tools/` 进交付物。
