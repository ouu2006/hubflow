### 1.1 许可结论（照 S-01 ~ S-06 的原文）

- **允许商用**：EPL 2.0 正文写明 "**intended to facilitate the commercial use**"（S-03）。
- **允许对外演示**：正文授予 "**publicly display, publicly perform**" 且 **royalty-free**（S-02）→ 答辩、评审、对外演示 SUMO 画面**不需要额外授权、不需要付费**。
- **本项目不分发 SUMO 本体** → **不触发 EPL 的源码公开义务**（S-04：义务只在"分发 Program"时触发）。本项目**只是运行** SUMO 与 `netconvert`、由 TraCI 以独立进程通信。
  - **一期不分发 SUMO 本体**（本 Issue 的完成判定之一）：交付物与演示物料里**不放** `sumo.exe` / `netconvert.exe` / `sumo-*.dll` / `tools/` **本体**；装法是"每台机器各自按本文件第 1.3 节安装"，**不是把 SUMO 打进交付包**。
  - **若将来要打包分发**（例如做成装机即用的交付物）：按 S-04 / S-05 随附**源码获取途径 + EPL 全文 + 不删原声明**，并在商业产品化时承担 §4 的 defend and indemnify（[`../docs/条款核实.md`](../../docs/条款核实.md) 结论表第 19 行）。
- **不要装 "all extras"**：Windows 的 "all extras" 安装含 **GPL 代码**，商用集成分发要避开（[`../docs/条款核实.md`](../../docs/条款核实.md) §1.4 S-05 一带）。本次装的是 **win64 标准包**（不含 extras）。
- **演示物料引用其输出时的标注**：仿真画面/仿真数据一律标 **"演示数据（模拟）"**；引用工具名写 **"Eclipse SUMO"**。**不得**把仿真结果说成实测（对外口径见 [`../docs/全流程计划.md`](../../docs/全流程计划.md) 第 1 节）。

### 1.2 本机安装结果（2026-10-10 实测）

| 项 | 值 |
|---|---|
| 安装形态 | **官方 win64 便携 zip**（不是 MSI）：`sumo-win64-1.28.0.zip`，**185,412,541 字节**，SHA256 `822aa9c57a07a895200d536fd2b3fe8785e36baa9b97ecbe75688e08a636fb8e` |
| 安装位置 | **`D:\app\SUMO`**（411 MB；`bin\` 可执行 + `tools\` Python 库 + `docs\tutorial\` 官方教程） |
| **为什么不走 MSI / winget** | `winget install EclipseFoundation.SUMO` 的 MSI **默认装到 `C:\Program Files (x86)\SUMO`，安装时不能选路径**。本项目开发机 **C 盘空间紧张（业主明确要求装 D 盘）**，且 C 盘那份还会**写机器级环境变量**（`SUMO_HOME` / `PATH` / `PYTHONPATH`，需管理员权限改）。**换机器请照抄 zip 装法**。<br>（本次误装的 MSI 已卸载干净：ARP 卸载条目已消失、机器级 `SUMO_HOME` / `PYTHONPATH` / `PATH` 里的 SUMO 项已清除、目录已删） |
| 环境变量（**用户级**，持久） | `SUMO_HOME=D:\app\SUMO`；`PATH` 追加 `D:\app\SUMO\bin` 与 `D:\app\SUMO\tools`；`PYTHONPATH` 追加 `D:\app\SUMO\tools`（TraCI / `sumolib` / `osmGet.py` 等工具要用） |
| 验证方式 | **新开进程**实测（不是当前 shell 里 export 就算数）：`%SUMO_HOME%` = `D:\app\SUMO`、`where sumo` → `D:\app\SUMO\bin\sumo.exe` |
| 说明 | 本机**不另装 pip 三件套**（`eclipse-sumo` / `traci` / `libsumo` / `sumolib`）——zip 包自带的 `tools\` 就是同一份 Python 库，用 `PYTHONPATH` 引即可。**若将来改用 pip 安装，必须锁 `traci==1.28.0`**（与本体同号，避免协议不匹配） |

### 1.3 换机器怎么装（照抄这五步）

```bash
# ① 下载官方 win64 zip（约 177 MiB）到非系统盘
curl -L -o /d/_tmp_sumo/sumo-win64-1.28.0.zip https://sumo.dlr.de/releases/1.28.0/sumo-win64-1.28.0.zip

# ② 解压到目标目录（示例：D:\app\SUMO），保持 bin/ tools/ 的层级
unzip -q sumo-win64-1.28.0.zip -d /d/app/_sumo_extract
cp -r /d/app/_sumo_extract/sumo-win64-1.28.0/. /d/app/SUMO/

# ③ 设三个用户级环境变量（PowerShell，不需要管理员）
#    SUMO_HOME = D:\app\SUMO
#    PATH      追加 D:\app\SUMO\bin; D:\app\SUMO\tools
#    PYTHONPATH 追加 D:\app\SUMO\tools

# ④ 新开一个终端，验版本与 Python 侧可用性
sumo --version
netconvert --version
python -c "import traci, sumolib; print(sumolib.version._version)"

# ⑤ 跑官方示例（Hello SUMO，教程在 %SUMO_HOME%\docs\tutorial\hello\data）
cd <一个可写目录> && cp "$SUMO_HOME"/docs/tutorial/hello/data/* ./
sumo -c hello.sumocfg --tripinfo-output tripinfo.xml --summary-output summary.xml
```

> **两个坑**（本次实测踩到，写下来省下一个人的时间）：
> 1. `sumolib` / `traci` **没有 `__version__` 属性**（`traci.__version__` 返回无意义的 `0.0.0`）。要版本就 `sumolib.version._version`（本机 = `'1.28.0'`）或看 `traci.constants.TRACI_VERSION`（本机 = `22`）。
> 2. **`sumo-gui` 截图不能只看退出码**：`traci.gui.screenshot()` 之后**必须再走一步仿真**（`simulationStep`）截图才真正落盘，否则命令返回成功而文件不存在——**与上游仓 `_write_frames()` 那个"假通过"是同一类问题**（[`现状核实.md`](现状核实.md) 第 4.3 节）。

### 1.5 一期怎么用（与本项目其它文件的接口）

- **一期主链路**：孪生由 SUMO 驱动（路网走 OSM + `netconvert`），自研司机行为体通过 **TraCI** 改路线 / 停靠 / 候客；虚拟检测器（E1 inductionLoop）出断面数；边界断面用 `<calibrator>` 做数据同化——**calibrator 只放边界 / 进口 edge，站内断面只放 E1**（依据 [`hubflow-data/03_技术事实_SUMO与数据同化.md`](../../docs/hubflow-data/03_技术事实_SUMO与数据同化.md) §3.6）。
- **路网产物**：`stations/sumo/*.net.xml` 归开发A（`netbuild.py` + `netedit`）；开发B 的 `map_ingest.py` **不重跑** `netconvert`。生成命令写 [`../work/twin/README.md`](../../work/twin/README.md)。
- **一期不分发 SUMO 本体**：演示脚本 `demo.bat` / `run_all.py` 只**调用**已安装的 SUMO，**不打包、不复制**其可执行文件与 `tools/` 进交付物。
