## 四、形状 / 取值差异说明（数据源不同，逐条登记）

- **数据源不同**：mock 取前端站点包（站点 Z 的 SZ 段 / 61 段真 OSM 路网占位基线 + 演示抖动）；traffic.py 取运行产物（感知 / 孪生 / 引擎 / 站点包），段号、条数、取值本就不同。**形状对照只比键集，不比取值。**
- **三层回落的层次职责**：engine routes.json 是**路线产物**（没有路段指标字段），所以 `/segments` 的回落链是 video → twin → stations 基线；engine routes 用于 route/recommend 与 locate，缺产物时这两端点如实 404 + note（不代算 ETA）。这不是跳过一层，是该层本来就没有路段指标。
- **route/recommend**：traffic.py 按契约 §二 端出引擎产物（含 od_id / reroute / quota / factors_note，arrival_route / alternatives 带 edges）；mock 是前端站点包的演示骨架（无上述契约字段）。以契约 §二 为准，差异已登记。
- **network**：mock 有真 OSM 几何 coords；traffic.py 的站点包 network.json 只有占位节点坐标（无经纬度），如实给空折线 coords: []，不编几何。
- **上游产物自身的口径问题（如实透传，不改数）**：运行产物里 video 链路的 ci=0 却给出 level=4（上游指标 / 判级口径不一致），traffic.py 按「只端数据」原样透出，不替上游改数；并排时 SEG-003 的 delta 会体现该差异。
- **站点身份与运行产物的命名空间**：meta / network 的站点身份取 `work/twin/site-ranges.json` 的 default_site（zhaoqingdong / 肇庆东站），而当前运行产物是样例网的段号命名空间——两者不一致是数据管线现状，接口层不硬编站点名、也不改数据。
- **vehicles**：`work/twin/out/vehicles.json` 是样例值（ts=2026-01-01、经纬度为占位），接口层如实透传，不拿合成车顶替；该端点二期下线。
- **heat-matrix / ci-history / predict**：接口层没有时序历史 / CI 预测产物：heat-matrix 只有当前桶有值、ci-history 只回当前单点、predict 点集为空；三者都带 note 说明，顶格键因此比 mock 多一个 note。
- **context**：天气 / 气温 / 能见度没有数据源：字段保留、值为 null 并在 note 说明；mock 的天气是站点包演示值。
- **alerts**：接口层没有预置告警剧本，按既有口径从 segments 快照派生（level ≥ 3）；mock 的 4 条四态告警来自站点包演示剧本。告警元素的可选留痕字段（channels / dispatch_at / dispatch_ratio_pct / writeback）在真正下发 / 回写后同样出现——对照表里的「alerts(下发后)」一行就是两边各做一次下发 + 回写后的形状比对。
- **thresholds**：ci_weights 的 key 用站点包 grading.weights 的指标名（x / v / L_q / T_d），mock 前端展示口径把排队项写成 k；rows 的刻度用站点包 level_bounds（v 是 km/h，mock 是速度比）。
- **unimplemented**：POST /factors、POST /scenario、POST /scenario/reset 是写快照端点：接口层只读快照，按本单口径如实 404 + note（不假装成功）。mock 侧是演示内存态。
- **写端点演示态**：plan/dispatch / plan/ack / alerts/reset / factors/reset 已实现，但演示态存在服务进程内存里（重启复位，与 mock 同性质）；README §二 要求正式落库留痕，属后续落库单。
- **未匹配方法**：照搬 mock 的纪律：未匹配路径 / 未注册方法一律 404（FastAPI 默认 405 已统一改 404），GET 打 POST-only 端点返回 404 而不是 405。
- **locate / report/compare**：契约 §七 列了这两个端点、mock 路由表没有：traffic.py 已实现（locate 取引擎孪生真值；report 无报表产物 → 空壳 + note），mock 侧 404。
